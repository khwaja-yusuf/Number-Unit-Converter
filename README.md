# Unit Converter

A beginner-friendly unit converter developed using C programming.

## Features

- Celsius to Fahrenheit
- Fahrenheit to Celsius
- Kilometres to Miles
- Miles to Kilometres
- Metres to Kilometres
- Kilometres to Metres
- Kilograms to Grams
- Grams to Kilograms

## Concepts Used

- Variables
- Data types
- `printf()` and `scanf()`
- Arithmetic operators
- `switch-case`
- Basic input and output
- Conditional logic

## How It Works

The program displays a menu of different unit conversions.

The user selects a conversion option, enters a value, and the program calculates and displays the converted value.
